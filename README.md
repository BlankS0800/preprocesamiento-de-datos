## 🌐 Acceso al Sitio Web (GitHub Pages)

👉 **[https://blanks0800.github.io/preprocesamiento-de-datos/](https://blanks0800.github.io/preprocesamiento-de-datos/)**

El sitio web es 100% interactivo y contiene:
1. **Resumen Ejecutivo:** Diagnósticos y métricas clave.
2. **Definición del Problema Empleado/Empleador:** Calidad del empleo, formalidad contractual, seguridad social y brechas salariales.
3. **Inventario de Variables:** Mapeo de atributos de entrada vs. salida.
4. **Bitácora Interactiva de Limpieza:** Registro de las 12 etapas con tarjetas colapsables/expandibles con auditoría antes y después.
5. **Análisis Exploratorio y Gráficos:** Visualizaciones analíticas y matrices de correlación.
6. **Arquitectura para Modelado ML:** Partición estratificada y variables predictoras.
7. **Conclusiones y Recomendaciones:** Hallazgos analíticos sobre el mercado laboral dependiente.
